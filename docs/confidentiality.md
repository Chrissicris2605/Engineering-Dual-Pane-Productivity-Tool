# Confidentiality notice

This repository is a public portfolio demo and was rebuilt from scratch with generic terminology, fictional data, and simplified behavior.

It does not contain:

- production source code;
- proprietary algorithms;
- real engineering files;
- company data;
- client data;
- internal naming conventions;
- confidential business logic;
- screenshots from private systems;
- real technical drawings.

The project exists only to demonstrate desktop productivity tooling, workflow-oriented UI design, and safe public documentation of professional engineering automation experience.

## Naming choices

The demo uses generic component IDs, component names, ownership labels, and status labels to avoid exposing terminology from any specific organization, industry workflow, or internal implementation.

## Visual choices

The diagram is drawn programmatically with fictional shapes and labels. No external technical drawings or private visual assets are used.
