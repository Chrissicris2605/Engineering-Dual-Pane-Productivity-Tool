# Public demo scope

This project is intentionally small, generic, and safe for public portfolio use.

## Included

- Dual-pane desktop interface
- Fictional technical assembly diagram
- Structured fictional component table
- Visual highlighting when selecting a table row
- Detail panel for selected components
- Clear selection action
- Documentation describing the safe public scope

## Not included

- Production business rules
- Real company templates
- Private file formats
- Advanced workflow integrations
- Internal review workflows
- Company-specific terminology
- Real technical drawings
- Real engineering data

## Future improvements

Potential public improvements may include:

- loading component data from CSV or JSON;
- saving review notes;
- filtering and searching components;
- richer diagram interactions;
- screenshot documentation;
- packaged Windows executable for demonstration.
